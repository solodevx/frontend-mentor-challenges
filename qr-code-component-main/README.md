# Frontend Mentor - QR Code Component

![Design preview for the QR Code Component](./preview.jpg)

## Overview

A responsive QR code component built as part of a Frontend Mentor coding challenge.

The goal was to recreate the provided design as accurately as possible while practicing HTML structure, CSS layout, typography, spacing, and responsive design.

## What I Learned

- How to structure a simple component using semantic HTML
- How to use Flexbox to center and position content
- How to work with fixed dimensions while keeping a component responsive
- How to control spacing, padding, border radius, and shadows
- How to match typography and colors from a provided design

## Challenges

The main challenge was accurately reproducing the spacing, sizing, typography, and positioning of the QR code card while keeping the component responsive across different screen sizes.

## Continued Development

I want to continue improving my ability to translate designs into clean and responsive CSS while paying closer attention to spacing, typography, and visual details.
