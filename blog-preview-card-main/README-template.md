# Frontend Mentor - Blog Preview Card

![Design preview for the Blog Preview Card](./preview.jpg)

## Overview

A responsive blog preview card built as part of a Frontend Mentor coding challenge.

The goal was to accurately recreate the provided design while practicing responsive layout, typography, spacing, and interactive states.

### Links

- Live Site: https://frontend-mentor-challenges-one-ruby.vercel.app/

## Built With

- HTML5
- CSS3
- Flexbox
- Responsive design
- CSS `@font-face`
- Local Figtree fonts

## What I Learned

- How to use local font files with `@font-face`
- How to build a responsive card using Flexbox
- How to use `object-fit: cover` to control image cropping
- How to create responsive typography with media queries
- How to implement hover states
- How to translate a Figma design into CSS while keeping the layout responsive

## Challenges

The main challenge was matching the design as closely as possible across different screen sizes.

I spent particular attention on the card dimensions, image sizing, spacing, typography, colors, border radius, shadow, and responsive behavior.

## Continued Development

I want to continue improving my ability to accurately translate designs into clean, responsive CSS while avoiding unnecessary fixed dimensions and keeping the code maintainable.
