# Blog Preview Card

![Blog Preview Card](./preview.jpg)

## Overview

A responsive blog preview card built from a Frontend Mentor design challenge.

The goal was to recreate the provided mobile and desktop designs as accurately as possible while keeping the layout responsive and the CSS maintainable.

## Links

- Live Site: [Blog Preview Card](https://frontend-mentor-challenges-one-ruby.vercel.app/)
- Frontend Mentor: [Solution](https://www.frontendmentor.io/solutions/blog-preview-5Ks_ZCS9Bs)

## Built With

- HTML5
- CSS3
- Flexbox
- Responsive Design
- Mobile-first workflow
- Local Figtree fonts

## What I Learned

- How to use local font files with `@font-face`.
- How to use Flexbox to structure and align the card.
- How to use `object-fit: cover` to control image cropping.
- How to create responsive layouts using media queries.
- How to implement hover states for interactive elements.
- How small differences in spacing, typography, and dimensions affect pixel accuracy.

## Challenges

One of the main challenges was matching the card dimensions, image sizing, spacing, typography, and responsive behavior to the provided design.

I also had to work through differences between the mobile and desktop layouts and learn how properties such as `width`, `padding`, `box-sizing`, `display`, and `object-fit` affect the final rendered dimensions.

## What I Would Improve

I would improve my initial CSS planning so that I can reach the final design faster without relying on as many small adjustments.

I would also continue refining my approach to responsive CSS so that the layout remains accurate while using fewer unnecessary fixed dimensions.
